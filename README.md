# QA Engineer Portfolio

A responsive personal portfolio website created as a GitHub practical project.

## Portfolio sections
- Home and About
- Hard Skills and Soft Skills
- Testing & Tech Tools
- Management & Collaboration Tools
- Selected projects: JCM Technologies, Volario, Airport Wayfinding, Reason Digital

## Technologies
- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

## Features
- Responsive design
- Light/Dark mode with localStorage
- Mobile navigation menu
- Project cards with details modal
- Contact form validation (demo only; does not send email)
- Keyboard-friendly modal
- Basic accessibility considerations

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Publish the repository from `main` / root using GitHub Pages.
